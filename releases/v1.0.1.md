# MacMiddleClick 1.0.1

The app is now built with the hardened runtime.

- macOS library validation is on and `DYLD_*` environment variables are ignored, so another process can no longer inject code into MacMiddleClick to borrow its Accessibility access.
- The release is signed with the same certificate as 1.0.0, so the Accessibility permission carries over. No settings need to change.
- No functional changes.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macmiddleclick
```

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macmiddleclick`.

Or download `MacMiddleClick.zip`, unzip it, quit any running copy, and replace **MacMiddleClick.app** in **Applications**.

On first launch, enable MacMiddleClick in **System Settings → Privacy & Security → Accessibility**.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
